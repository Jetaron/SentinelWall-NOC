# SentinelWall NOC — Мультисервісний CCTV Моніторинг

**SentinelWall NOC** — це централізована панель оперативного моніторингу (Network Operations Center), яка об'єднує дашборди та метрики різних інфраструктурних сервісів на одному екрані за принципом стіни камер відеоспостереження (CCTV).

---

## Основні можливості

- **Стіна камер спостереження (CCTV Matrix Wall):**
  - Одночасний моніторинг **Wazuh SIEM**, **Zabbix**, **Ceph (Seph) Object Storage**, **Redis Cluster**, **RabbitMQ** та будь-яких власних сервісів чи API-ендпоінтів.
  - Перемикання сітки відображення: `2x2`, `3x2`, `3x3` або `1x1` та повноекранний режим кожної камери.
  - Групування за категоріями (*Безпека (SIEM)*, *Інфраструктура*, *Сховище даних*, *Черги та Кеш* або власні групи).
- **Гнучке керування оновленням даних:**
  - Індивідуальне налаштування періоду опитування для кожної камери (`1с`, `2с`, `3с`, `5с`, `10с`, `30с`) або глобальне встановлення періоду для всіх сервісів.
  - Режим **Авто-циклу сторінки** (`15с`, `30с`, `60с`) та можливість призупинення/відновлення потоку телеметрії.
- **Чорна скринька 20–30 секунд (Flight Recorder):**
  - Безперервний кільцевий буфер на **30 секунд** (частота 1 Гц) для кожного сервісу.
  - У разі критичного збою система автоматично фіксує посекундний дамп метрик за останні **20–30 секунд** перед аварією, визначає першопричину (*Root Cause Analysis*) і пропонує кроки відновлення.
- **Конструктор дашбордів та графіків (Chart.js):**
  - Створення власних віджетів на основі отриманих метрик із вибором типу графіка **Chart.js**: лінійний (`line`), стовпчиковий (`bar`), радарний (`radar`) або кільцевий (`doughnut`).
- **Хмарний журнал запитів, пошук та бекапування:**
  - Зберігання історії запитів та телеметрії у хмарному сховищі (`/api/cloud/*`) з миттєвим текстовим пошуком, фільтрацією за групами, статусами та діапазоном дат.
  - Створення автоматичних (при збої) та ручних резервних копій логів і конфігурації з можливістю повного відновлення стану в один клік або імпорту/експорту `.json`.
- **Сповіщення Telegram і Slack та експорт звітів:**
  - Інтеграція з **Telegram Bot API** та **Slack Incoming Webhooks** для миттєвого оповіщення чергової зміни разом зі зведенням метрик за останні 30 секунд.
  - Експорт звітів у форматах **PDF** (із підтримкою кирилиці та таблиць аварійного дампу) та **CSV**.
- **Захист від випадкових видалень та адаптивний інтерфейс:**
  - Діалогове меню підтвердження для всіх операцій видалення сервісів, графіків чи очищення демонстраційних параметрів.
  - Темна нічна тема (за замовчуванням для цілодобових чергувань NOC) і світла денна тема, повна адаптивність для мобільних пристроїв, планшетів та великих екранів.

## Технологічний стек

- **Frontend:** React 19, TypeScript, Tailwind CSS 4, Lucide Icons
- **Візуалізація та звіти:** Chart.js (`react-chartjs-2`), `jsPDF` (PDF-генерація), CSV-експортер
- **Backend:** Node.js, Express (`server.ts`), Vite Middleware, файлове хмарне сховище `.data/cloud-storage.json`
- **Тестування:** Вбудований тестовий раннер Node.js (`node:test`, `node:assert/strict`)

## Запуск та розробка

1. **Встановлення залежностей:**
   ```bash
   npm install
   ```

2. **Запуск сервера розробки (порт 3000):**
   ```bash
   npm run dev
   ```

3. **Запуск модульних тестів:**
   ```bash
   npm test
   ```

4. **Збірка для продакшену та перевірка типів:**
   ```bash
   npm run lint
   npm run build
   ```
